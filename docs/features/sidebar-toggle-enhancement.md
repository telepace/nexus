# 侧边栏收缩功能增强

## 概述

为了提升用户体验，我们在Telepace的侧边栏中添加了更直观的收缩按钮，让用户能够更容易地发现和使用侧边栏的展开/收缩功能。

## 实现的功能

### 1. 头部收缩按钮
- **位置**: 侧边栏展开状态下，位于品牌标志（Telepace）右侧
- **图标**: 使用面板图标（PanelLeftClose/PanelLeftOpen）
- **交互**: 点击即可收缩/展开侧边栏
- **视觉**: 带有工具提示，显示"收起侧边栏"或"展开侧边栏"

### 2. 边缘hover按钮
- **位置**: 侧边栏右边缘，仅在鼠标悬停时显示
- **图标**: 使用箭头图标（ChevronLeft/ChevronRight）
- **交互**: 点击即可收缩/展开侧边栏
- **视觉**: 带有阴影效果，提供良好的视觉反馈

### 3. 原有功能保持
- **SidebarRail**: 原有的边缘拖拽区域继续工作
- **键盘快捷键**: Cmd/Ctrl + B 快捷键继续工作
- **移动端适配**: 在移动端自动切换为合适的交互方式

## 技术实现

### 新增组件
- `SidebarToggleButton`: 专门的侧边栏收缩按钮组件
  - 支持不同大小（sm/md/lg）
  - 支持不同图标类型（chevron/panel）
  - 支持边缘显示模式
  - 集成工具提示功能
  - 使用Framer Motion提供平滑动画

### 修改的组件
- `AppSidebar`: 在头部区域添加收缩按钮
- 添加了group类以支持hover效果

## 用户体验改进

1. **发现性更强**: 用户可以直观地看到收缩按钮
2. **多种交互方式**: 提供头部按钮、边缘hover、拖拽区域等多种操作方式
3. **视觉反馈**: 按钮有hover效果和工具提示
4. **动画效果**: 平滑的图标切换动画

## 使用方法

用户现在可以通过以下方式收缩/展开侧边栏：

1. **点击头部按钮**: 在Telepace标志右侧的面板图标
2. **鼠标hover边缘**: 将鼠标移动到侧边栏右边缘，点击出现的箭头按钮
3. **原有方式**: 点击或拖拽侧边栏右边缘的隐藏区域
4. **键盘快捷键**: 使用 Cmd/Ctrl + B

## 兼容性

- ✅ 桌面端浏览器
- ✅ 移动端自适应
- ✅ 键盘导航
- ✅ 屏幕阅读器支持（通过aria-label）

## 配置选项

SidebarToggleButton组件提供以下配置选项：

```tsx
interface SidebarToggleButtonProps {
  className?: string;           // 自定义样式
  size?: "sm" | "md" | "lg";   // 按钮大小
  showOnEdge?: boolean;         // 是否显示在边缘
  iconType?: "chevron" | "panel"; // 图标类型
  showTooltip?: boolean;        // 是否显示工具提示
}
```
