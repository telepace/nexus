# Content Library 内容库

## 概述

Content Library 是一个现代化的内容管理界面，提供了强大的搜索、筛选和视图切换功能。设计灵感来自于日式极简美学，注重用户体验和视觉一致性。

## 主要功能

### 🔍 智能搜索
- **全文搜索**: 支持标题、描述、标签的全文搜索
- **实时搜索**: 输入时实时显示搜索结果
- **紧凑布局**: 搜索框集成在工具栏中，节省空间

### 🏷️ 标签筛选
- **智能标签提取**: 自动从AI分析结果中提取标签
- **多标签筛选**: 支持同时选择多个标签进行筛选
- **标签计数**: 显示每个标签对应的内容数量
- **紧凑显示**: 选中标签以简洁方式显示，超过2个时显示"+N"

### 📊 排序选项
- **时间排序**: 按创建时间排序（最新优先）
- **评分排序**: 按AI质量评分排序（高分优先）
- **标题排序**: 按标题字母顺序排序
- **热度排序**: 按阅读时间等指标排序

### 👁️ 视图模式
- **网格视图**: 单列卡片式布局，展示丰富的内容信息
- **列表视图**: 紧凑的列表布局，适合快速浏览

## 布局设计

### 新版工具栏布局
采用紧凑的单行布局设计，优雅地将所有控制元素整合：

```
[筛选] [已选标签] ———— [搜索框] ———— [排序] [视图切换]
```

#### 布局特点：
- **左侧区域**：筛选下拉菜单 + 紧凑的已选标签显示
- **中间区域**：自适应宽度的搜索框（最大宽度限制）
- **右侧区域**：排序选择 + 视图切换按钮

#### 响应式适配：
- 搜索框使用 `flex-1` 自适应宽度，但限制最大宽度为 `max-w-md`
- 左右两侧使用 `shrink-0` 确保不被压缩
- 已选标签区域限制最大宽度，超出时滚动显示

### 内容布局
- **单列网格**: 每行显示一个内容卡片，更加优雅
- **左侧栏宽度**: 640px（大屏672px），为单列布局提供充足空间
- **卡片居中**: 使用 `max-w-2xl mx-auto` 确保卡片居中显示

## 组件架构

### 核心组件

#### `Toolbar.tsx`
重新设计的工具栏组件，采用紧凑单行布局
- 三段式布局：筛选区 + 搜索区 + 控制区
- 自适应宽度分配
- 响应式标签显示

#### `ContentCard.tsx`
内容卡片组件，支持两种视图模式
- 网格模式：丰富的单列卡片布局
- 列表模式：紧凑的列表布局
- 统一的交互体验

#### `ContentList.tsx`
内容列表容器组件
- 单列网格布局（`grid-cols-1`）
- 居中显示（`max-w-2xl mx-auto`）
- 动画过渡效果

### 工具函数

#### `utils/filtering.ts`
筛选和排序逻辑
- `matchesSearch()`: 搜索匹配函数
- `matchesTags()`: 标签匹配函数
- `sortItems()`: 排序函数
- `filterAndSortItems()`: 主筛选函数
