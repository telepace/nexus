# Content Library 内容库

## 概述

Content Library 是一个现代化的内容管理界面，采用日式极简美学设计，提供了强大的搜索、筛选和视图切换功能。注重用户体验和视觉一致性，追求简洁优雅的设计风格。

## 设计风格

### 🎨 日式极简美学
- **纯净背景**: 纯白背景（#ffffff）搭配极细边框
- **微妙交互**: 轻柔的悬浮效果和过渡动画
- **统一标签**: 去除彩色标签，使用统一的浅灰色样式
- **简约排版**: 细腻的字体重量和间距设计
- **呼吸感布局**: 充足的留白和舒适的视觉节奏

### 🎯 颜色系统
```css
--library-bg: #ffffff;              /* 纯白背景 */
--library-border: rgba(0, 0, 0, 0.06);      /* 极细边框 */
--library-border-hover: rgba(0, 0, 0, 0.12); /* 悬浮边框 */
--library-text: #000000;            /* 主要文字 */
--library-text-muted: #666666;      /* 次要文字 */
--library-text-subtle: #999999;     /* 辅助文字 */
--library-tag-bg: rgba(0, 0, 0, 0.04);      /* 标签背景 */
--library-tag-bg-hover: rgba(0, 0, 0, 0.08); /* 标签悬浮 */
```

## 主要功能

### 🔍 智能搜索
- **全文搜索**: 支持标题、描述、标签的全文搜索
- **实时搜索**: 输入时实时显示搜索结果
- **紧凑布局**: 搜索框集成在工具栏中，节省空间

### 🏷️ 标签筛选
- **智能标签提取**: 自动从AI分析结果中提取标签
- **多标签筛选**: 支持同时选择多个标签进行筛选
- **标签计数**: 显示每个标签对应的内容数量
- **紧凑显示**: 选中标签以简洁方式显示，超过2个时显示"+N"
- **统一样式**: 所有标签使用一致的浅灰色样式，无彩色区分

### 📊 排序选项
- **时间排序**: 按创建时间排序（最新优先）
- **评分排序**: 按AI质量评分排序（高分优先）
- **标题排序**: 按标题字母顺序排序
- **热度排序**: 按阅读时间等指标排序

### ⭐ 评分系统
- **五星评级**: 采用自定义星形图标，使用星形路径剪切
- **金色填充**: 使用amber-400颜色填充已激活的星星
- **数值显示**: 显示精确的数值评分（如4.1/5.0）

### 👁️ 视图模式
- **网格视图**: 单列卡片式布局，展示丰富的内容信息
- **列表视图**: 紧凑的列表布局，适合快速浏览

## 布局设计

### 新版工具栏布局
采用紧凑的单行布局设计，优雅地将所有控制元素整合：

```
[筛选] [已选标签] ———— [搜索框] ———— [排序] [视图切换]
```

#### 布局特点：
- **左侧区域**：筛选下拉菜单 + 紧凑的已选标签显示
- **中间区域**：自适应宽度的搜索框（最大宽度限制）
- **右侧区域**：排序选择 + 视图切换按钮

#### 响应式适配：
- 搜索框使用 `flex-1` 自适应宽度，但限制最大宽度为 `max-w-md`
- 左右两侧使用 `shrink-0` 确保不被压缩
- 已选标签区域限制最大宽度，超出时滚动显示

### 内容布局
- **单列网格**: 每行显示一个内容卡片，更加优雅
- **左侧栏宽度**: 640px（大屏672px），为单列布局提供充足空间
- **卡片居中**: 使用 `max-w-2xl mx-auto` 确保卡片居中显示

### 卡片设计 - 日式极简风格

#### 网格视图卡片
- **纯白背景**: 使用 `bg-white` 确保纯净感
- **极细边框**: `border-black/6` 提供微妙的边界
- **悬浮效果**: 
  - 边框变深: `hover:border-black/12`
  - 微妙阴影: `hover:shadow-lg hover:shadow-black/8`
  - 轻微上移: `hover:-translate-y-0.5`
- **渐变overlay**: 悬浮时显示微妙的白色渐变覆盖层
- **圆角**: 使用 `rounded-md` 保持适度的圆角
- **紧凑布局**: 评分、阅读时间、处理状态和发布时间在同一行显示

#### 列表视图布局
- **极简边框**: 仅显示底部分割线 `border-b border-black/4`
- **轻微背景**: 悬浮时使用 `hover:bg-black/2` 提供反馈
- **紧凑布局**: 12列网格系统，合理分配空间
