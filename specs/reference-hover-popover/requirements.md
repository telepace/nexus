# 需求文档

## 介绍

在content-library的右侧预览区域，当LLM回复的内容块包含引用链接（如ref="2-3"）时，用户悬浮在引用链接上应该弹出悬浮卡片，显示原文的对应片段并高亮相关段落。

## 需求

### 需求1 - 悬浮卡片显示原文片段

**用户故事:** 作为用户，当我悬浮在LLM回复中的引用链接（如#ref-3）上时，我希望看到一个悬浮卡片显示原文第3段的内容

#### 验收标准

1. When 用户悬浮在引用链接上时，系统shall 在500ms后显示悬浮卡片
2. When 引用为单个数字（如ref="3"）时，卡片shall 显示第3段的完整内容
3. When 引用为范围（如ref="2-3"）时，卡片shall 显示第2-3段的合并内容并标注范围

### 需求2 - 原文段落高亮定位

**用户故事:** 作为用户，当悬浮卡片显示时，我希望左侧的原文区域能自动滚动到对应段落并高亮显示

#### 验收标准

1. When 悬浮卡片显示时，系统shall 自动滚动左侧原文到对应段落位置
2. When 引用为范围（如ref="2-3"）时，系统shall 高亮第2段和第3段
3. When 鼠标离开引用链接时，系统shall 在2秒后移除高亮效果

### 需求3 - 引用格式兼容性

**用户故事:** 作为用户，我希望系统能识别当前产品中使用的各种引用格式

#### 验收标准

1. When 引用格式为"ref='1,2,3'"时，系统shall 正确解析为多个独立引用
2. When 引用格式为"ref='1-3,5,7-9'"时，系统shall 正确解析为混合格式引用
3. When 原文数据不可用时，系统shall 显示降级提示信息而不是错误
