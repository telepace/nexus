# 优雅引用交互体验需求文档

## 介绍

基于用户反馈，当前引用功能的点击和显示效果不够优雅，需要设计一套极简的、统一的、高品质的引用交互体验。采用 TDD 方式深度思考交互细节，创造出类似 Notion、Linear 等现代应用的优雅体验。

## 需求

### 需求1 - 统一的引用交互模式

**用户故事：** 作为用户，我希望所有引用都采用统一的交互模式，避免混乱的体验。

#### 验收标准

1. When 鼠标悬浮到引用标记时，系统应当显示优雅的预览卡片，延迟 150ms 触发
2. When 用户点击引用标记时，系统应当打开详细的引用内容面板
3. When 用户移开鼠标时，系统应当平滑隐藏预览卡片，延迟 200ms
4. When 用户按 ESC 键时，系统应当关闭所有打开的引用面板

### 需求2 - 极简优雅的视觉设计

**用户故事：** 作为用户，我希望引用的视觉设计简洁优雅，不干扰主要内容的阅读。

#### 验收标准

1. When 引用以内联形式出现时，系统应当显示为简洁的圆形数字标记，直径 18px
2. When 悬浮预览卡片显示时，系统应当采用微妙的阴影和渐变，具有磨砂玻璃效果
3. When 动画播放时，系统应当使用弹性缓动曲线，持续时间不超过 300ms
4. When 在暗色模式下时，系统应当自动适配暗色配色方案

### 需求3 - 智能的悬浮行为

**用户故事：** 作为用户，我希望悬浮行为足够智能，不会意外触发或误关闭。

#### 验收标准

1. When 鼠标快速划过引用标记时，系统应当不触发悬浮预览（防抖）
2. When 鼠标移动到预览卡片上时，系统应当保持卡片显示状态
3. When 预览卡片接近屏幕边缘时，系统应当智能调整位置，避免被裁切
4. When 同时悬浮多个引用时，系统应当只显示最后悬浮的那个

### 需求4 - 流畅的动画效果

**用户故事：** 作为用户，我希望所有动画都流畅自然，提升使用愉悦感。

#### 验收标准

1. When 预览卡片出现时，系统应当同时播放透明度、缩放和位移动画
2. When 引用标记被悬浮时，系统应当有微妙的缩放和阴影变化反馈
3. When 切换引用内容时，系统应当使用淡入淡出过渡，避免闪烁
4. When 在低性能设备上时，系统应当自动减少动画复杂度

### 需求5 - 优雅的详情面板

**用户故事：** 作为用户，我希望点击引用后能看到详细的、格式良好的引用内容。

#### 验收标准

1. When 点击引用标记时，系统应当在页面中央显示模态面板
2. When 详情面板显示时，系统应当支持拖拽移动，提供触觉反馈
3. When 引用内容过长时，系统应当提供平滑的滚动体验
4. When 面板打开时，系统应当显示"定位原文"按钮，点击后关闭面板并跳转

### 需求6 - 响应式和无障碍支持

**用户故事：** 作为用户，我希望在任何设备上都能获得良好的引用体验。

#### 验收标准

1. When 在移动设备上时，系统应当将悬浮改为轻触，长按显示预览
2. When 使用键盘导航时，系统应当支持 Tab 键聚焦和 Enter 键激活
3. When 使用屏幕阅读器时，系统应当提供清晰的语义标记和描述
4. When 在小屏幕上时，系统应当优化面板大小和位置

## 设计原则

1. **极简主义**：移除一切不必要的视觉元素
2. **渐进增强**：基础功能优先，高级交互渐进增强
3. **性能优先**：所有动画和交互必须保持 60fps
4. **统一性**：所有引用相关组件使用统一的设计语言

## 成功指标

- 用户引用点击率提升 40%
- 引用相关的用户反馈问题减少 80%
- 动画性能保持在 60fps 以上
- 支持所有主流浏览器和设备类型
