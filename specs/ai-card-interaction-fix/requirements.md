# 需求文档

## 介绍

AI卡片交互功能存在严重问题，用户无法正常选择文本进行复制操作，同时卡片上的按钮（折叠展开、收藏、分享等）交互不稳定，影响用户体验。需要修复这些交互问题。

## 需求

### 需求1 - 文本选择功能修复

**用户故事:** 作为用户，我希望能够在AI卡片中选中任意文本并进行复制操作，就像在普通网页中一样。

#### 验收标准

1. When 用户在AI卡片内容区域按住鼠标拖拽时，系统应当正确高亮选中的文本区域。
2. When 用户鼠标松开后，选中的文本应当保持高亮状态，不会立即取消选择。
3. When 用户右键点击选中文本时，系统应当显示上下文菜单允许复制操作。
4. When 用户使用Ctrl+C快捷键时，选中的文本应当被正确复制到剪贴板。
5. When 用户点击卡片外部区域时，文本选择状态才应当被清除。

### 需求2 - 按钮交互稳定性修复

**用户故事:** 作为用户，我希望AI卡片上的所有按钮（折叠展开、收藏、分享等）都能稳定响应我的鼠标操作。

#### 验收标准

1. When 用户鼠标悬停在按钮上时，按钮应当始终显示hover效果（颜色变化、阴影等）。
2. When 用户点击折叠展开按钮时，卡片应当正确执行折叠或展开动画。
3. When 用户点击收藏按钮时，收藏状态应当正确切换并提供视觉反馈。
4. When 用户点击分享按钮时，分享功能应当正确触发。
5. When 按钮处于hover状态时，点击操作的响应时间应当在100ms内。

### 需求3 - JSON扩展按钮hover功能修复

**用户故事:** 作为用户，我希望在鼠标悬浮在可扩展的JSON内容上时，扩展按钮能够稳定显示并正确响应我的操作。

#### 验收标准

1. When 用户鼠标悬浮在标记为expandable的JSON内容上时，系统应当始终显示扩展按钮（💭图标）。
2. When 扩展按钮显示时，用户应当能够看到hover效果和tooltip提示。
3. When 用户点击扩展按钮时，应当正确触发AI深度展开功能。
4. When 用户鼠标移出JSON内容区域时，扩展按钮应当正确隐藏。
5. When JSON内容在AI卡片中渲染时，扩展按钮的交互不应当受到父容器事件的干扰。

### 需求4 - 层级和事件处理优化

**用户故事:** 作为用户，我希望卡片的不同交互区域（内容区、按钮区、JSON扩展区）能够独立正确地响应我的操作，不会相互干扰。

#### 验收标准

1. When 用户在内容区域进行文本选择时，不应当触发卡片的选中状态变化。
2. When 用户点击按钮时，不应当同时触发卡片的点击事件。
3. When 有多个交互元素重叠时，应当优先响应最上层元素的交互。
4. When 用户进行文本选择操作时，不应当受到其他交互元素的阻挡。
5. When JSON扩展按钮显示时，其hover和click事件应当优先于父容器的事件处理。
