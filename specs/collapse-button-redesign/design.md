# 技术方案设计

## 架构概述

基于现有的 React + TypeScript + Framer Motion 技术栈，设计新的折叠展开按钮组件，提供多种图标方案供选择。

## 技术栈

- **前端框架**: React 18 + TypeScript
- **动画库**: Framer Motion
- **图标库**: Lucide React
- **样式**: Tailwind CSS
- **组件库**: 现有的 UI 组件系统

## 技术选型

### 图标方案设计

提供以下几种图标方案：

1. **方案A - 箭头方案**: ChevronDown/ChevronUp
   - 优点：语义清晰，通用性强
   - 缺点：相对常见

2. **方案B - 圆形箭头方案**: ArrowDownCircle/ArrowUpCircle
   - 优点：视觉层次丰富，现代感强
   - 缺点：占用空间稍大

3. **方案C - 三角形方案**: TriangleDown/TriangleUp
   - 优点：简洁明了，视觉冲击力强
   - 缺点：可能需要自定义图标

4. **方案D - 圆形展开方案**: CircleDot/Circle
   - 优点：极简设计，现代感十足
   - 缺点：语义可能不够直观

5. **方案E - 线条方案**: MinusSquare/PlusSquare
   - 优点：保持原有语义，但更精致
   - 缺点：与现有设计差异不大

### 动画设计

使用 Framer Motion 实现以下动画效果：

1. **旋转动画**: 图标围绕中心点旋转（折叠时向上，展开时向下）
2. **缩放动画**: 点击时的微缩放反馈
3. **形态变化**: 图标之间的平滑过渡
4. **颜色过渡**: 悬停和激活状态的颜色变化
