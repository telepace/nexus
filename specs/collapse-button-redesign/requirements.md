# 需求文档

## 介绍

当前界面中的卡片折叠展开按钮使用的是加号(+)和减号(-)图标，视觉效果不够美观。需要重新设计一套更优雅的图标方案，并添加流畅的动画过渡效果，提升用户体验。

## 需求

### 需求1- 折叠展开按钮图标重新设计

**用户故事:** 作为用户，我希望看到更美观的折叠展开按钮图标，而不是简单的加号减号，这样能提升界面的整体美观度。

#### 验收标准

1. 当用户查看卡片时，折叠展开按钮应当显示为美观的箭头图标，而不是加号减号
2. 当用户点击折叠展开按钮时，图标应当有流畅的180度旋转动画过渡效果
3. 图标应当保持语义清晰：折叠时箭头向上，展开时箭头向下
4. 图标应当与整体界面设计风格保持一致
5. 动画效果应当平滑自然，持续时间适中（200-300ms）

### 需求2- 动画交互效果优化

**用户故事:** 作为用户，我希望在点击折叠展开按钮时看到流畅的动画效果，这样能提供更好的交互反馈。

#### 验收标准

1. 当用户点击按钮时，图标应当有平滑的形态变化动画
2. 动画应当使用 framer-motion 库实现
3. 动画持续时间应当在 200-300ms 之间
4. 动画应当有适当的缓动函数（ease-in-out）
5. 动画效果应当与现有的界面动画风格保持一致
